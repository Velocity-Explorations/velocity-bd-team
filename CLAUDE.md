# CLAUDE.md

AGENTS.md holds this repo's instructions: read it first. This file adds where Velocity's company knowledge and BD
history live, for any session that drafts, refines or assesses a proposal.

- **Sources of truth:** the six files in the BD Proposal Library's `01 Company Reference` folder, and the
  `00 Proposal Register` (BD history), on the "Velocity Business Development" shared drive. Read them live by
  file id every time, never from a cached copy, an earlier export or memory.
- **Facts:** company facts, past performance, products and people come only from those files. A fact they don't
  hold is written `[NEEDS FACT: ...]`, never invented. Check 05 Conflicts before using a fact, and flag any fact
  tied to an open CF item.
- **Every draft** ends with a "Facts used" list citing the F, PP, PR and PE ids it rests on.

File ids, the rules for people, entities, SENSITIVE items and the Brand Guide, and how to use the Register:
[docs/velocity-knowledge.md](docs/velocity-knowledge.md).
