# Account menu

Part of the Velocity Theme app components (26 Oct 2026). Tokens are in tokens-app.css; the card is in card.css.

- A menu from the account button: the person (36px initials, name, one line on what deciding means), Profile settings, Table settings (on Calls), Switch user, Log out.
- Until Google sign-in is live, Switch user lists the allowed people; an account not on the list shows Cannot decide and any decision is refused with a line saying who can add it.
