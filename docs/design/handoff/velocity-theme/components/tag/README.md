# Tag

Part of the Velocity Theme app components (26 Oct 2026). Tokens are in tokens-app.css; the card is in card.css.

- 20px high, 1px #434343 line, radius 3px, Inter Tight 11.5px #BEBEBE. The type tag comes first, in the info tone.
- Tags sit on their own line under the details and badges, never mixed with them. Each tag is focusable and its source (the call’s data, Claude, Grok) shows on hover and on keyboard focus.
