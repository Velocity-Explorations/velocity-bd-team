# View cards

Part of the Velocity Theme app components (26 Oct 2026). Tokens are in tokens-app.css; the card is in card.css.

- A row of 7c cards (see components/card) on one grid with shared rows, so labels, numbers and descriptions line up.
- A card that switches the table below is a button with aria-pressed; the pressed one is the selected card. A card that opens another page is a link with an arrow in its band.
- The first card holds the count that needs the person, in the accent. Switching cards keeps the bar’s portal, tag and open or closed filters and resets the column filters and sort.
