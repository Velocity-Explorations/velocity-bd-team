# Button

Part of the Velocity Theme app components (26 Oct 2026). Tokens are in tokens-app.css; the card is in card.css.

- Primary: ink fill (#F5F5F5), ground text, 600 weight. One per area (Save, Apply, Draft proposal, Approve). Never the accent.
- Secondary: transparent or surface fill, 1px #434343 line, ink text; hover line #757575.
- Text button: ink text underlined in #757575, for Clear filters, Reset to defaults, Add a note.
- Heights: 30px, or 28px in table rows and menus. Radius 4px. Icons 14px, 6px from the label.
- Disabled: text #555555, no hover. Focus: 2px accent outline, offset 2px.
