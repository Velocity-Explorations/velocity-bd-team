# Field

Part of the Velocity Theme app components (26 Oct 2026). Tokens are in tokens-app.css; the card is in card.css.

- Input, select and textarea on #1A1A1A with a 1px #434343 line, radius 4px, ink text 13px to 14px.
- Height 34px on settings pages, 30px in bars. Labels above in the caps label style; help text 12px #959595 below.
- A search box carries a 14px search icon and applies on Enter (say so in the placeholder).
- Checkbox: a 16px square with a 1px line and an 8px ink square when ticked. Radio card: a bordered option with a ring; the chosen one gets a 2px ink border and the raised surface.
- Segmented switch (All, Open, Closed): one 30px box, options split by 1px lines, the chosen one on #434343 at 600 weight, role radiogroup.
