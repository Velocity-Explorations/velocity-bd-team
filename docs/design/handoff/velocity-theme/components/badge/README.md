# Badge

Part of the Velocity Theme app components (26 Oct 2026). Tokens are in tokens-app.css; the card is in card.css.

- 18px high, 1px tone line, radius 3px, a 6px square in the tone, then the word in Chakra Petch 11px 600.
- Tones: good (yes, Pursue, kept, completed, won), caution (maybe, members only, opens 28 Oct), conflict (no, judges: yes vs no, people disagree, errors), info (Submitted, services), neutral (not reviewed, undecided, Not relevant, Dismiss, closed, lost).
- The word is always written; colour never carries meaning alone.
