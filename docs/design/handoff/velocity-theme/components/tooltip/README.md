# Tooltip

Part of the Velocity Theme app components (26 Oct 2026). Tokens are in tokens-app.css; the card is in card.css.

- Shows a control’s title text when it gets keyboard focus, so hover-only facts are reachable without a mouse.
- #333333 fill, 1px #555555 line, radius 4px, 12.5px ink text, up to 360px wide, 6px below the element; role tooltip; hides on blur.
