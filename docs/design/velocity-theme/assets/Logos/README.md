# Logos

Velocity's lockup (the VX mark beside the VELOCITY wordmark) and the mark alone, as transparent PNGs cut from the same artwork. Single ink each: pick the file by its ground, since an image can't take a CSS color.

- `velocity-lockup-white.png`: white (#FFFFFF), for `ground` and other dark grounds. 3139×559, 5.6:1. The default.
- `velocity-lockup-ink.png`: ink (#1E1E1E), for light grounds and print.
- `velocity-mark-white.png`: the VX mark alone in white, for small spaces. 723×559.
- `velocity-mark-ink.png`: the VX mark alone in ink.

Set the lockup by height: 36px on the cover (`logo-height`), 40px on the closing slide (`logo-height-closing`), on the 1920 slide.
