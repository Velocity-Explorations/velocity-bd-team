# MilestoneList

Milestone codes and names in rows, separated by hairlines.

```html
<div class="vx-section">
  <p class="vx-label">Key milestones</p>
  <ul class="vx-milestones">
    <li><span class="vx-numeral">M1</span><span class="vx-body">Eleven portals scanning</span></li>
    <li><span class="vx-numeral">M2</span><span class="vx-body">Review queue with two judges</span></li>
  </ul>
</div>
```

- Codes in `vx-numeral` (`accent`) in a 204px column (`numeral-column`); names in `vx-body` (`ink`).
- Hairlines sit between rows, not above the first or below the last.
