# SectionSlide

A divider between parts of a briefing: eyebrow, one display title, a short rule and one line, centered on the warm glow.

```html
<section class="vx-slide vx-slide--section">
  <div class="vx-center">
    <p class="vx-eyebrow">Collaborative exercise</p>
    <h2 class="vx-display">Prioritization</h2>
    <div class="vx-rule vx-rule--hero"></div>
    <p class="vx-lead">Rank the open decisions by what they unblock.</p>
  </div>
</section>
```

- Provide: an eyebrow, a title of one to three words, and one sentence.
- Use it when the room changes activity (an exercise, a discussion), not before every topic.
