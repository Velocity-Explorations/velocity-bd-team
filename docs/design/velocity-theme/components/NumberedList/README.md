# NumberedList

Two columns of zero-padded numbers and lines, a hairline under each, for an agenda or any ordered set of up to eight.

```html
<ol class="vx-numbered">
  <li><span class="vx-numeral-lg">01</span><span class="vx-lead">Team introductions and points of contact</span></li>
  <li><span class="vx-numeral-lg">02</span><span class="vx-lead">Scope and objectives</span></li>
</ol>
```

- Up to eight items. The grid fills the left column first, four rows each.
- Numbers in `vx-numeral-lg` (`accent`), text in `vx-lead` (`ink`), one line each.
- Pair it with a footer of timings: `30 min briefing | 30 min discussion`.
