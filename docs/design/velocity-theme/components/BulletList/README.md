# BulletList

Lines marked with square bullets: `accent` squares for our items or the main list, grey squares for anyone else's.

```html
<ul class="vx-bullets vx-body">
  <li>Keyword filter, then two AI judges</li>
  <li>Tags from a set list on every call</li>
</ul>
```

- Put the type class on the `ul`: `vx-body` (6px bullets) or, with `vx-bullets--lead`, `vx-lead` (8px bullets) for key objectives.
- `vx-bullets--secondary` for a partner's list, `vx-bullets--muted` for out of scope. Their text goes `ink` or `ink-secondary` to match.
- Outside a card, add `vx-bullets--inset` (8px in from the edge).
- Three to five items, one line each where possible.
