# Tag

A small bordered label for a feature, tool or channel.

```html
<div class="vx-tags">
  <span class="vx-tag vx-caption">Briefs</span>
  <span class="vx-tag vx-caption">Drafts</span>
</div>
<div class="vx-tags vx-tags--lg">
  <span class="vx-tag vx-tag--lg vx-small">Slack</span>
  <span class="vx-tag vx-tag--lg vx-small">Email</span>
</div>
```

- `vx-tag` (18px text, `line-strong` border) inside roadmap bars; `vx-tag--lg` (24px text, `line` border) for channels and tools in a card.
- Text only, in `ink-secondary`. No fills, no icons.
