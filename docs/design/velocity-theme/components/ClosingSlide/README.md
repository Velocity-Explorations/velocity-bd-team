  <div class="vx-foot vx-foot--ruled"><p class="vx-small vx-ink-muted">Velocity Explorations, Inc. | velocityexplorations.com</p></div>

- Provide: the closing title, the subject line (identifier and name, split by a middle dot) and the marking as the program writes it.
- The glows mirror the cover's: cool top left, warm bottom right.
